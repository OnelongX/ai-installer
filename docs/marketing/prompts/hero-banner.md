# Composition
Layout: a 16:9 hero banner. Left third — large title stack (English title + Chinese subtitle). Right two-thirds — a stylized abstract terminal window floating in dark space with a single blinking cursor and a clean progress bar that visually morphs into a lightning bolt, hinting at "fast / one-click install". Decorative cyan particles and soft radial glow surround the terminal. Faint isometric grid in the background. Whitespace 40-50%.

Main visual elements:
- A minimalist terminal window outline with rounded corners and 3 traffic-light dots, glowing cyan edge.
- A horizontal install progress bar near the bottom of the terminal, half-filled with electric blue gradient. Its right tip stretches forward into a sharp lightning bolt shape that bursts out of the window — symbolizing speed.
- Two small CLI prompt symbols: a `>` chevron and a `▮` blinking cursor inside the terminal.
- Soft scattered cyan and violet light particles.
- Subtle isometric grid lines fading into the background.
- Optional: two tiny logo silhouettes (an abstract `C` ring and a stylized atom/spark) at small scale on either side of the terminal, hinting at Claude + Codex without using their real logos.

Color scheme: background #050B1A → #0A1530 deep navy gradient. Primary glow #38BDF8 (cyan). Secondary accent #818CF8 / #A855F7 (electric violet). Text #F0FDF4 (near white). Progress bar gradient #22D3EE → #6366F1.

Rendering notes: crisp vector geometry, soft outer glow on terminal and progress bar, subtle inner shadows, no photographic textures, no people, no offices, no chairs, no laptops. Modern dev-tool dashboard aesthetic, similar to Vercel / Linear / Raycast marketing visuals.

Type notes (hero): single dominant visual subject (terminal + lightning), supported by typography. Strong focal point. No clutter.

Palette notes (dark): rich blacks, neon cyan and violet accents, never dull, high contrast text.

# Negative
NO: real human faces, hands, photographic people, office workstation, stock-photo vibes, warm orange/yellow, beige, pastel, hand-drawn doodle, retro pixel, cluttered icons, real OpenAI / Anthropic logos, real Windows logo.
